# LumaPod — Ambient + True Gaze Upgrade

Implemented:
- Gentle ambient audio is ON by default and persists between visits.
- Global sound control remains visible and can switch all sound off for sensory comfort.
- Ambient sound profiles: Calm Drift, Soft Piano, Rain Atmosphere, Ocean Atmosphere.
- Entering a Pod automatically adapts the ambient sound profile to the environment.
- Puzzle audio now sits as a softer musical layer rather than a generic one-size-fits-all tone.
- True full-screen Gaze mode: hides the entire Pod menu and leaves only the moving scene.
- Tap the environment once to restore controls.
- “Show controls” escape button is available.
- Gaze mode stays separate from the Luma conversation.
- Service worker cache bumped to v8.

The environment visuals remain locally rendered, so they are crisp and offline-friendly.
